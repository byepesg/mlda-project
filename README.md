# mlda-project

## Orden de trabajo

Este proyecto sigue una secuencia recomendada para el análisis de datos y la validación del flujo de trabajo:

1. 1_AdquisicionIntegracionDatos.ipynb
   - Recolección e integración de los datos iniciales.
2. 2_AnalisisExploratorioDatos.ipynb
   - Exploración, limpieza y visualización inicial de las variables.
3. 3_AnalisisEstadisticoDescriptivo.ipynb
   - Estadísticas descriptivas y resumen del comportamiento de los datos.
4. 4_CalidadDeLosDatos.ipynb
   - Evaluación de calidad, inconsistencias y tratamiento de datos faltantes.
5. Copy_of_M1U3_fase_2_Entendimiento_de_los_datos (2).ipynb
   - Copia/versión complementaria para revisión de entendimiento del dataset.

## Convención de nombres

- Los archivos principales comienzan con un número que indica el orden de ejecución.
- Los nombres usan mayúsculas/minúsculas en formato descriptivo, por ejemplo: AdquisicionIntegracionDatos, AnalisisExploratorioDatos, etc.
- Las copias o versiones alternativas se identifican con prefijos como "Copy_of_" o con sufijos entre paréntesis.

## Recomendación

Se recomienda abrir y ejecutar los notebooks en orden numérico para mantener una narrativa consistente del proyecto.
